# Ethiopia Cybersecurity Awareness System

## Overview

This project is a beginner-friendly cybersecurity awareness and digital safety training system developed using Python.

The main purpose of this project is to help users understand important cybersecurity concepts such as:

* Phishing
* Malware
* Password Security
* Public WiFi Risks
* Two-Factor Authentication (2FA)
* Safe Browsing
* Online Privacy and Security

## Features

* 20 cybersecurity awareness questions
* Multiple-choice answer system
* Input validation
* Scoring and percentage calculation
* Personalized feedback
* Cybersecurity tips and awareness guidance

## Technologies Used

* Python

## Purpose of the Project

I developed this project to improve my Python programming skills and strengthen my understanding of cybersecurity awareness concepts.

This project is also inspired by the importance of digital safety and Ethiopia’s growing digital transformation initiatives.
